# 🌆 Dhule Darshan – Explore My Hometown

**Dhule Darshan** is a web-based platform designed to showcase the beauty, culture, food, and attractions of Dhule city. The goal of this project is to provide users with complete information about places to visit, local food, hotels, and nearby travel options in one place.

---

## 🚀 Features

* 🏨 Hotel Listings with basic details
* 🍛 Famous Food Places in Dhule
* 📍 Tourist Attractions & Nearby Locations
* 🚗 One Day Trip Planning
* 🗺️ Location-based exploration

---

## Project Status

>  **Currently Under Development (Pending Phase)**

This project is not fully live yet due to the following reasons:

* Database integration is still in progress
* Real-time booking system is not activated
* Hotel booking feature requires **permission from hotel owners**
* Backend APIs are under development/testing phase
